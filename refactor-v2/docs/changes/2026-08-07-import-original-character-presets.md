# Импорт оригинальных персон CharacterMaker

Дата: 2026-08-07
Ветка: `refactor/domain-catalog-v2`
Supabase project: `charmaker`

## Цель

Перенести в публичную библиотеку CharacterMaker V2 персон, которые существовали в оригинальном React-прототипе, не создавая новых характеристик и не перезаписывая уже актуализированную Лайвет.

## Метод импорта

Импорт выполнен через штатный RPC `public_upsert_preset('character', payload)`, а не прямыми INSERT в одну таблицу.

Поэтому для каждой новой Персоны одновременно созданы:

- запись в `characters`;
- `schema_version = character-state-v3`;
- `metadata.editor_schema = character-state-v3`;
- полный `metadata.editor_state` для актуального редактора;
- нормализованные `character_parameter_values`;
- запись в `mutation_requests` с idempotency key;
- запись в `audit_log`.

Все импортированные Персоны имеют `status=active` и `is_public=true`, что соответствует текущей публичной модели проекта без пользовательских аккаунтов.

## Правила переноса

Постоянные параметры внешности и тела перенесены из оригинального `profile` в актуальные stable ID каталогов V2.

Новое поле V2 `breastSizeId` отсутствовало в оригинальном проекте. Для импортированных женских персон установлено `null`, без искусственного вычисления по обхвату груди.

У мужских оригинальных пресетов старый объект технически содержал скрытые женские поля груди/ягодиц. Они не перенесены в активный `CharacterState` и выставлены `null`, поскольку в V2 эти параметры не относятся к мужской Персоне.

У Наны в старом исходнике была опечатка `eyelinerStyle: "Крылая"`. Она нормализована в существующий stable ID `winged` (`Крылатая`). Информация о нормализации сохранена в `metadata.import_origin.normalization_notes`.

У Эльфийского Рейнджера возраст `125` сохранен точно как в оригинальном пресете. БД допускает возраст до 200, хотя текущий UI-каталог возраста имеет диапазон 16-90. Это известное legacy-несоответствие и оно зафиксировано в metadata.

## Одежда из старых character presets

Оригинальный CharacterProfile одновременно содержал параметры Персоны и одежды. В V2 домены разделены на `Персона` и `Образ`, поэтому одежда не была смешана с новым `CharacterState`.

Для каждой импортированной Персоны сохранено имя исходного `clothingPreset` в `metadata.import_origin.legacy_clothing_preset`, а immutable source blob SHA позволяет восстановить полный старый outfit при отдельной миграции Образов.

На этом шаге новые `outfit_presets` и `character_outfits` не создавались.

## Проверка после импорта

Проверка живой Supabase БД после транзакции показала:

- active/public Персон: `14`;
- список active/public в точности соответствует 14 оригинальным именам, с актуальной Лайвет;
- все 13 новых записей имеют `character-state-v3`;
- все 13 новых записей имеют `metadata.editor_schema=character-state-v3`;
- normalized parameter rows созданы для каждой записи;
- мужские Персоны имеют по 24 нормализованных параметра;
- женские Персоны имеют 28-32 параметра в зависимости от makeup/tattoo;
- Lain и Victoria June сохранили текст описания татуировок;
- существующая Лайвет не изменена.

## Итог

Публичная библиотека Персон V2 теперь содержит весь оригинальный набор CharacterMaker из 14 имен, при этом новая каноническая версия Лайвет имеет приоритет над старой legacy-версией.
