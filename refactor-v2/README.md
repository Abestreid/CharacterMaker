# CharacterMaker Refactor V2

Mobile-first React-интерфейс и типизированный domain-слой параметров CharacterMaker.

## Реализовано

- рабочий Vite + React + TypeScript frontend;
- адаптивная навигация: нижняя панель на телефоне и sidebar на desktop;
- редактор персонажа со всеми текущими параметрами внешности и тела;
- редактор пяти слоев одежды, материалов, цветов и аксессуаров;
- редактор сцены: 46 поз, 14 движений, 32 эмоции, камера, 55 фонов, свет, стиль и фильтры;
- загрузка локального референса сцены с сохранением MIME-типа и метаданных;
- отдельный экран «Все списки», автоматически построенный из `CATALOG`;
- поиск, фильтрация по категориям и просмотр стабильных `id`;
- локальное сохранение черновика через Zustand persist;
- стартовые значения, валидаторы, миграция и тесты каталогов.

## Ограничения этапа

Пока отсутствуют:

- пресеты персонажей;
- пресеты одежды;
- пресеты фотосессий;
- генерационная логика и API;
- backend и серверное хранилище;
- реальные изображения предпросмотра персонажа.

## Запуск

```bash
npm install
npm run dev
```

Production-проверка:

```bash
npm run build
npm run check
```

## Архитектурные правила

1. Состояние хранит стабильные английские `id`.
2. Русский текст используется в `label`.
3. UI получает значения только из domain-каталогов.
4. Большие каталоги открываются через поисковую мобильную панель.
5. Новые каталоги автоматически появляются на экране «Все списки».
6. Пресеты позднее смогут ссылаться только на существующие `id`.
