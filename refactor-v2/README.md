# CharacterMaker Domain V2

Изолированный типизированный domain-слой параметров CharacterMaker.

## Состав

- каталоги персонажа, одежды и сцены;
- стабильные английские `id` и русские `label`;
- числовые диапазоны;
- модели состояния;
- стартовые значения;
- конфигурация форм;
- валидаторы;
- миграция старых строковых значений;
- тесты целостности и количества.

## Ограничения этапа

В папке отсутствуют:

- пресеты персонажей;
- пресеты одежды;
- пресеты фотосессий;
- API и генерационная логика;
- зависимости от Gemini или Google;
- React-компоненты текущего приложения.

## Запуск проверки

```bash
npm install
npm run check
```

## Правила расширения

1. Состояние хранит только стабильные `id`.
2. Русский текст используется только в `label`.
3. Новое значение добавляется в профильный каталог.
4. Значения по умолчанию должны проходить валидацию.
5. Пресеты могут ссылаться только на существующие `id`.
